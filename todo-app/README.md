# To-Do List Application

A modern, feature-rich to-do list application built with React, Vite, and Tailwind CSS. All your tasks are automatically saved to your browser's local storage!

## ✨ Features

- ✅ **Add, Edit, Delete Tasks** - Full CRUD functionality
- 💾 **Local Storage** - Automatically saves all tasks to your browser
- 🎯 **Priority Levels** - Organize tasks by priority (Low, Medium, High)
- 📅 **Due Dates** - Set and track task deadlines
- 🔍 **Search & Filter** - Find tasks easily with search and filter options
- 📊 **Statistics Dashboard** - Track your progress with real-time stats
- 📱 **Responsive Design** - Works perfectly on desktop and mobile
- ⚡ **Fast & Lightweight** - Built with Vite for lightning-fast performance
- 🎨 **Beautiful UI** - Modern design with Tailwind CSS

## 🚀 Quick Start

### Installation

```bash
cd amami/todo-app
npm install
npm run dev
```

Opens at `http://localhost:5173`

### Build for Production

```bash
npm run build
npm run preview
```
